# 目錄

1. [PART 1：單張照片描述](#part-1)
   概念：分成單人照片、兩人以上的照片、事物與風景照片三種。單人 / 多人照片要抓照片中人物「正在做的動作」，最容易被聽起來合理但實際沒發生的動作描述（例如聽到眼鏡、帽子、皮帶等單字就直覺選答案）誤導；事物與風景照片沒有人物，重點在物品所處的「狀態」，常考現在進行式被動語態（is being + Vpp）描述「正在被做」的動作，如果照片中的動作其實已經完成，就會變成陷阱選項。整體最常見的陷阱是「利用照片中真的出現的物品（手錶、椅子、褲子等）去描述一個並未真正發生的動作或位置」，聽到關鍵字先別急著選，要確認動作和狀態是否真的相符。

2. [PART 2：問答題](#part-2)
   概念：涵蓋 What / Who / When / Where / Why / How / Which 等疑問句，以及 Be 動詞開頭、助動詞開頭、否定疑問句、附加疑問句、選擇疑問句、要求疑問句、提議疑問句和敘述句等句型。作答關鍵在於先聽懂句首的疑問詞或句型，判斷該回答「具體資訊」（What/Who/When/Where/Why/How/Which）還是「Yes/No 類的回應」（Be 動詞 / 助動詞 / 否定 / 附加疑問句，也可以用同義的肯定或委婉說法取代單純的 Yes/No）；要求或提議疑問句則要聽對方是答應、婉拒還是提出替代方案；敘述句要抓住陳述內容並選出邏輯呼應的回覆。常見陷阱是選項中出現和題目「發音相似」或「同一語意範疇容易聯想到」的字來誤導考生，一定要聽清楚句子實際的問法方向再作答。
